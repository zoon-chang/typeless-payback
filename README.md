# typeless-payback

Typeless(타입리스) 연간 결제 10% 페이백 안내 정적 사이트.

- 배포: Vercel (`vercel --prod`)
- 구조: 순수 정적 HTML 단일 페이지 (`index.html`) + `robots.txt` + `sitemap.xml`
- SEO: FAQPage JSON-LD, OG/Twitter 메타, canonical

지급 정책 요약: 연간 플랜($144) 데스크톱 결제 → 실결제액 10%($14.40)를 결제일 +35일 이내 토스/카카오페이 원화 지급. 30일 내 환불 시 소멸.
